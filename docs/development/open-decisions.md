# 수치·가정 기록

모든 수치는 근거(논문·데이터·사용자 입력·측정)가 있어야 한다. 근거가 없는 값은 "근거 없음"으로 남기고, 근거가 생기면 고친다.

## 경로 엔진 (`src/backend/jeju_lifepath/routing/optimizer.py`)

| 항목 | 값 | 근거 | 남은 한계 |
|---|---|---|---|
| 지표 가중치 | 모두 1.0 (동일 가중) | 제주 실증 추정치가 없을 때 동일 가중이 견고함: Dawes (1979) Am. Psychol. 34:571 | 제주 데이터로 추정되면 교체(G4). 논문 효과크기는 가중치로 쓰지 않음(REQ §5) |
| 지표 방향 | CCTV·조명 유리, 범죄·사고·기상 불리 | REQ §10 연구(Piza 2019, Welsh 2022)의 방향만 사용 | 효과 크기는 사용 안 함 |
| 유동인구 제외 | 가중치 0 | REQ §5: 목적(고립/혼잡 회피)에 따라 방향이 다름 | 목적 선택 UI 생기면 포함 |
| λ (경로 유형) | 최단 0, 균형 0.25, 안전환경 0.50 | **근거 없음.** 비율 r만큼 긴 경로(q1)가 짧은 경로(q0)를 이기는 조건은 r < (1+λq0)/(1+λq1)−1이고, λ는 q=1→0일 때의 최대 감수 우회율. 정책 상한 0.50에서 유도했을 뿐이며 상한 자체도 근거 없음(ARCH "초기 정책") | 제주 경로 선택 자료로 추정(Basu & Sevtsuk 2022 방법) |
| 자료 없는 구간 q | 탐색 가능한 구간 중 관측된 q의 길이가중 평균 | 고정 상수 대신 데이터에서 계산. 단, 평균 대치의 타당성은 결측이 무작위일 때만 성립(Little & Rubin) — **제주 자료로 검증 안 됨** | 지표 조합이 다른 q를 섞음, 지역 편향 가능. 자료 비율을 화면에 표시하고 비교 불가 기준은 G4에서 |
| 일반 보행 속도 | 1.31 m/s (78.6 m/분) | 건강한 성인 실외 보통 걸음 메타분석: Murtagh et al. (2021) Sports Med., PMID 33030707 | 노인·어린이 동반 시 더 느림 |
| 휠체어 속도 | 1.04 m/s (62.4 m/분) | 숙련 수동휠체어 사용자 170명 자기선택 속도 (PMC4631660) | **고정식 에르고미터 실험값이라 실외 적용 미검증**. 전동휠체어 미반영 |
| 유모차 속도 | 일반 보행값 | **근거 없음**: 보행 속도 연구를 찾지 못함 | 미검증 표시 |
| 후보 경로 수 상한 | 200 | **근거 없음**(알고리즘 예산). 실제 제주 그래프에서 시간 측정 후 정함 | 상한 내 못 찾으면 최단 경로로 대체(문구 표시) |
| 평행 구간 | 전부 후보(가상 중간 노드) | 근거 불필요(정확성 수정) | — |

## 실데이터 받기 (2026-11-17, `scripts/fetch_jeju_data.py`)
- 와이파이: 가장 최근 날짜 하나만 받음. 최근 날짜는 첫 페이지 100건의 최댓값으로 정함(최신순 정렬 가정, 미검증). 틀리면 지난 날짜 자료를 받음.
- 약국: 상태에 "폐업·휴업·취소"가 들어간 곳 제외. **현재 좌표 없음(주소만)** → 공공기관 지오코더로 좌표를 붙이기 전에는 ingest 불가(spec이 좌표 열을 요구). (지난 시험: 카카오 장소 매칭으로 245/70/3곳 처리했으나 카카오 저장 금지 정책 확인 후 결과 전부 삭제.)
- 치안시설: 시도코드 50만 남김. 좌표계 EPSG:3857은 값 크기로 추정했고, 변환 후 100% 제주 범위 안에 들어와 맞는 것으로 봄.
- 허브 자료 라이선스: 미확인(허브 이용약관 확인 필요). 배포 전 확인해야 함.
- 교통사고 다발지역 42곳: 연도 구분이 없고 "제주시1/제주 제주시1"처럼 묶음 이름이 두 형식 → 서로 다른 기간·기준 자료가 섞였을 수 있음. 미확인.
- 허브 페이지 순서가 호출마다 달라 한 번 받으면 줄이 겹치고 빠짐(와이파이 3,141건 중 고유 약 2,160). 여러 번 받아 합치도록 바꿈. 20번 받아 고유 3,047건까지 모였고, 나머지 94건은 원자료의 완전 중복으로 추정(미검증). 두 번 연속 새 줄이 없으면 멈춤.
- 허브 받기 안전장치: 1회 실행 전체 HTTP 호출 상한 400회(재시도·모든 자료 포함, 근거 없음, 한도 약 700회보다 낮게), 페이지 수가 전체 건수를 넘으면 중단, 응답 형식 검사, 빈 자료는 저장 거부, 모자라면 실패(와이파이만 경고 후 저장 허용).
- 허브는 자료별 하루 호출 한도가 있음("Today's quota is full", 와이파이 약 700회 호출 후). 한도 수치는 미확인. 현재 와이파이 파일은 한 번만 받은 판(중복·누락 있음) → 한도 풀린 뒤 다시 받기.
- 카카오 로컬 API 결과(좌표·주소·가공값)는 저장·캐싱 금지(devtalk 공식 답변 2026-08~10). 장소ID·URL만 저장 가능. 약국 좌표는 공공기관 지오코더로 붙여야 함.

| 로그인 시도 제한 | 없음 | PoC라 생략. 비밀번호 무차별 대입에 약함 |

| 오류 문구 | 프레임워크 기본 영어 문구는 상태별 한국어 문장으로 바꿈 | 사용자 화면에 내부 문구 금지 규칙 |
