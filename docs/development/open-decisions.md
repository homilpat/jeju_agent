# 임의로 정한 값·가정 기록

근거가 없는 숫자, 휴리스틱, 검증 안 된 가정을 모아 둔다. 근거가 생기면 해당 줄을 고치거나 지운다.

| 항목 | 위치 | 값/가정 | 이유 | 틀리면 |
|---|---|---|---|---|
| 지표 가중치 | `src/backend/jeju_lifepath/routing/optimizer.py` `_WEIGHTS` | CCTV·조명·범죄·사고 1.0, 기상 0.5 | 동작 확인용 잠정값(`provisional-v0`). G4 근거 없음 | 안전환경 우선 경로 순위가 근거 없이 정해짐 |
| λ (경로 유형별 패널티) | 같은 파일 `_LAMBDA` | 최단 0, 균형 1, 안전환경 3 | 세 경로가 서로 달라지게 하려는 잠정값 | 균형/안전환경 경로 차이가 과하거나 없음 |
| 유동인구 제외 | 같은 파일 | `activity_index` 가중치 0 | 방향이 사용자 목적에 따라 다름(REQ §5) | 고립/혼잡 회피 요청을 반영 못 함 |
| 결측 구간 q | 같은 파일 `NO_DATA_Q` | 0.5 (중립) | 0이면 자료 없는 길이 가장 안전해 보임 | 자료 없는 길이 과하게 불리하거나 유리해짐 |
| 보행 속도 | 같은 파일 `WALK_M_PER_MIN` | 75 m/분 (4.5 km/h) | 일반 성인 보행 속도 통념, 출처 없음 | 소요 시간 안내가 틀림(특히 휠체어·유모차) |
| 후보 경로 수 상한 | 같은 파일 `MAX_CANDIDATES` | 200 | 작은 그래프에서 충분, 실그래프 미측정 | 큰 그래프에서 느리거나, 상한 안 경로를 못 찾아 최단으로 대체 |
| 평행 구간 처리 | 같은 파일 `_collapse` | 노드 쌍마다 비용 최소 구간 1개만 | 구현 단순화 | 더 짧은 평행 구간이 우회 상한 판단에서 빠짐 |
| 지표 수준 문구 경계 | `presentation/route.py` `_level` | 0.67 이상 높음, 0.34 이상 보통 | 3등분, 근거 없음 | "높음/보통/낮음" 표현이 실제와 어긋남 |
| 출처 이름 | `presentation/route.py` `_source_name` | `synthetic:` 접두어면 합성 데이터, 나머지는 "출처 확인 필요" | 레지스트리 표시명 연동 전 임시 | 실데이터 출처 이름이 화면에 안 나옴 |
| 사용자 문구 누출 검사 | `tests/backend/fixtures/user_text.py` | 정규식(괄호·밑줄·대문자 2자+·`A-B` 형태 ID), CCTV만 허용 | 글자 패턴 추정 | 다른 형태의 ID·코드는 못 잡음 |
| 절대경로 검사 | `tests/backend/unit/test_repo_paths.py` | 드라이브+Users, `/c/Users`, `/Users`, `/home` 패턴 | 흔한 개인 경로 패턴 | 다른 형태의 개인 경로는 못 잡음 |
