# 해커톤 평가·제출 규칙 (참고자료)

대회 안내 페이지 내용을 옮겨 적은 것이다(2026-11-18 사용자 제공, 대회 규칙 Updated 26.11.10 기준).

## 1. 평가

최종 수상팀 = **내부 전문가 평가 70% + ELO 기반 참가팀 상호 평가 30%**.

### 1) ELO 기반 참가팀 상호 평가 (30%)

- 상호 평가 기간: 2026-11-23(월) 12:00 ~ 2026-11-27(금) 10:00
- 최종 제출을 완료한 참가팀만 대상.
- 데이콘 Elo 평가: 평가자가 두 산출물을 비교해 더 나은 쪽에 투표하고, 투표 결과를 Elo 산식으로 계산해 리더보드 점수에 반영한다.
- 자기 팀 제출물은 투표 화면에 나오지 않는다.
- **최소 투표 횟수에 못 미치면 그 팀의 투표·득표가 평가에 반영되지 않는다(No Vote, No Gain).**
- 상호평가 단계에서는 **기획서만 공개**된다(최종 결과물 ZIP은 심사위원 평가에 쓰임).

### 2) 내부 전문가 평가 (70%)

평가 기간: 2026-11-23(월) 12:00 ~ 2026-11-27(금) 23:59

| 평가항목 | 배점 | 평가내용 |
|---|---|---|
| 분석 주제의 타당성과 창의성 | 15 | 분석 주제의 참신성과 활용 목적의 명확성 |
| 필수 데이터 활용 적절성 | 20 | 지정 데이터 1종 이상의 실질적 활용과 분석·처리 방법의 적절성 |
| AI Agent 기술성 및 완성도 | 25 | 목표에 따른 도구·데이터 활용과 주요 기능의 안정적 수행 |
| 편의성 및 실용성 | 25 | 사용자 편의성과 실제 서비스 활용 가능성 |
| 결과 신뢰성 및 재현성 | 15 | 결과 근거·한계의 명확성과 코드·매뉴얼을 통한 재현 가능성 |
| **합계** | **100** | |

동점일 때 우선순위: ① AI Agent 기술성 및 완성도 → ② 편의성 및 실용성 → ③ 필수 데이터 활용 적절성. 그래도 같으면 심사위원 합의 또는 재심사.

단계별 평가 비율: 참가자 상호 평가는 제출자 100%, 전문가 평가는 심사위원 100%.

## 2. 참여 규칙

- 개인 또는 팀(최대 5인). 개인은 팀 신청 없이 참여 가능.
- 동일인은 개인 또는 여러 팀에 중복 등록할 수 없다.
- 팀 빌딩 페이지에서 팀을 만들었으면 제출 전에 팀장이 대회 안내 페이지에서 **"팀으로 전환"** 을 완료해야 한다.

## 4. 대회 규칙 및 유의사항 (Updated 26.11.10)

### 4.1 제출 및 AI 도구 활용

- 생성형 AI·AI 개발 도구를 쓸 수 있다.
- 최종 제출 때 **사용 AI 모델, AI 활용 범위, 외부 API·서비스, 외부 데이터, 오픈소스·외부 코드**를 명시해야 한다.

### 4.2 외부 데이터 및 API

- 필수 데이터 외 공개 데이터·외부 API는 적법하게 쓸 수 있는 경우에만 사용한다.
- 쓴 데이터·자료의 출처를 분명히 적는다.
- 외부 서비스 의존성은 개발·탑재 계획과 실행 매뉴얼에 적는다.
- 제주데이터허브 등 데이터 API의 **실제 키는 제출물에 넣지 않고**, 키 발급·설정 방법을 실행 매뉴얼에 적는다.
- 외부 LLM 등 AI API를 쓰면 평가에 필요한 **평가용 키는 참가자가 준비**하고 비용도 참가자가 낸다.
- 평가용 외부 AI API 키는 최종 결과물 ZIP의 실행환경·매뉴얼에 넣어 제출할 수 있다. 사용 한도를 걸어 제출할 수 있고, **평가 기간이 끝나면 키를 삭제·폐기**한다.

### 4.3 개인정보 및 보안

- 개인정보·금융정보·인증정보·API 키 같은 민감정보를 코드·발표자료·영상에 넣지 않는다.
- API 키는 원칙적으로 넣지 않는다(외부 AI API 평가용 키만 4.2에 따라 예외).
- 외부 서비스 이용약관과 보안 기준을 지킨다.
- 결과물에 개인정보가 드러나지 않게 하고, 필요하면 가명처리한다.

### 4.4 저작권 및 부정행위

- 데이터·이미지·코드·모델은 적법하게 쓸 수 있어야 한다.
- 타 공모전 수상작이나 이미 공개·상용화된 결과물을 그대로 내면 안 된다.
- 표절·저작권 침해·허위 기재 등이 나중에 드러나면 평가 제외 또는 수상 취소될 수 있다.

### 4.5 결과물 검증

- 운영진이 정상 작동과 사실관계 확인을 위해 코드 실행을 요청할 수 있다.
- 실행환경·모델·데이터·API 이용 내역 등 추가 자료를 요청할 수 있다.
- 결과물이 발표·시연과 크게 다르면 평가·수상에 반영될 수 있다.

### 4.6 결과물 소유권

- 모든 결과물은 제주빅데이터센터에 속하며, 시상작은 제작자 이름(팀명)으로 센터에서 제공될 수 있다.
