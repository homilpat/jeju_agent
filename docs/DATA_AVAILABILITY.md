## 2. 결론

- **공식 제주 데이터 요건(G1) 후보로 가장 유력한 것은 센터 도로 링크·노드·교통량(반출 가능 표시)이다.** 단, "반출 가능" 표시는 확보가 아니며, 실제 반출·파싱·분석을 끝내야 G1 통과다. 받으면 카카오 길찾기 API 없이 차량 경로를 계산할 수 있지만 회전 제한을 반영하지 못하고 경로선이 실제 도로 모양과 다르다.
- 빵집 목록은 허브 음식점 목록(통합)에 제과점이 들어 있는지 확인이 먼저다. 없으면 빵집 기능의 공식 데이터 근거가 약해진다.
- 메뉴는 공식 데이터로 매장별 제공이 불가능하다(반출 불가·집계 자료). 카카오맵 검색 링크로 안내한다.
- 도보 경로는 제주 보행망이 없어 외부 보행망이 필요하다. 안전환경 지표 중 조명·범죄·유동인구는 쓸 수 있는 제주 자료가 없다 → 안전환경 경로에 쓸 수 있는 후보는 CCTV·교통사고 2개뿐이며, 이것도 좌표 컬럼이 확인돼야 가능하다. 둘 다 안 되면 안전환경 경로는 "자료 없음"으로 표시한다.
- 마감(2026-11-20 10:00)까지 공식 자료를 하나도 못 받으면 합성 데이터 시연(DEMO 표시)으로 제출하며 공식 데이터 사용을 주장하지 않는다(REQ §9).

## 4. 결정 (2026-11-16): 빅데이터센터 미사용

사용자 결정으로 빅데이터센터(위 표의 "센터" 항목)는 쓰지 않는다. 제주데이터허브 자료와 외부 길찾기 API만 쓴다.

- 허브 목록에는 도로 링크·노드·소요시간 자료가 없다(975 도로현황, 980 지방도로현황은 노선 대장 링크로 보이며 경로 계산용 그래프 아님, 미확인).
- 경로·소요시간은 외부 API로 받는다: 차량은 카카오모빌리티 길찾기 API, 도보 길찾기는 카카오모빌리티 유료 제휴로만 제공(devtalk 안내, 2026-11 확인) → 도보 경로는 OSM 도로망으로 직접 계산.
- 안전환경 경로 알고리즘은 도로망(그래프)이 있어야 돈다. 허브·API 모두 그래프를 주지 않으므로 OpenStreetMap 제주 도로망(ODbL, 출처 표시 필요)을 그래프로 쓰는 안을 검토 중. 그러면 기존 알고리즘을 그대로 쓰고, API는 차량 소요시간 보정에만 쓴다. 대안은 API 후보 경로를 점수로 순위만 매기는 방식(선택 폭이 좁음). 미결정.
- 허브에서 받을 것: 510 CCTV, 493 교통사고 다발지역, 571 음식점(통합), 495 약국, 720 공공와이파이. 979 교통신호기 설치현황은 좌표가 있으면 보조 지표 후보.

### 5.1 공식 도로 길이와 대조

공식 자료: 국토교통부 「2021 도로현황조서」(2021-12-31 기준) 65쪽 시·도별 도로 현황, 제주도 행.

| 구분 | 공식(개통) | OSM | 해석 |
|---|---|---|---|
| 지방도 | 711.4 km | 번호(`ref`) 붙은 차도 742~988 km | 아래 값은 일방통행 길을 모두 절반으로, 위 값은 그대로 센 것. 실제 분리 차도 쌍을 가려내지 않아 **범위로만 표시**. `ref`가 지방도 번호인지 노선 목록과 대조하지 않음 |
| 도로법상 도로 전체 | 2,877.0 km | 차도 약 6,000 km | 집계 대상이 다름(OSM에는 농어촌도로·사도·단지 내 길 포함, 분리 차도 이중 계산). 비교 불가, 참고만 |

- 시점이 다르다(공식 2021년 말, OSM 2026년 11월).
- **결론: 지방도 수준에서 크게 어긋나지 않는다는 정도만 말할 수 있다.** 노선별 대조와 읍면별 골목 완전성은 미실시. 골목 완전성 대조 후보: 행정안전부 도로명주소 도로구간 자료.

- 본섬 최대 덩어리 도보 길 9,453 km.
- 1 km 이상 떨어진 덩어리 17개: 섬(추자도 62 km·2 km, 우도 73 km, 가파도 15 km, 비양도 6 km, 마라도 6 km)과 본섬 안 조각(가장 큰 것 18 km 산간 산책로, 9 km 리조트 내부, 나머지 1~3 km). 본섬 조각은 위치만 확인했고 원인(실제 단절인지 OSM 누락인지)은 미확인.

### 5.4 큰 차도의 보행 처리

| 항목 | 결과 |
|---|---|
| 큰 차도(`trunk`·`primary`·`secondary`·`tertiary`와 각 연결로) | 2,591 km |
| 보도 정보 태그가 있는 비율(차도+보행로 길이 기준) | 1.3%, 그중 "이 차도에 보도가 붙어 있음"은 0.3% |
| 자동차전용도로 표시(`motorroad=yes`) | 0 km(실제 지정 여부는 미확인, 0건이 보행 허용의 증거는 아님) |
| 큰 차도 제외 실험 | 큰 차도 중 보도가 붙어 있다고 표시된 것만 남기고 빼면, 본섬 도보 길이의 **17.0%**만 가장 긴 덩어리에 남음(길이 기준). 시험 경로 5개 모두 **끊김** |

- 법: 도로교통법 제8조는 보도가 있으면 보도로, 보차도 구분이 없으면 길 가장자리 등으로 통행하도록 정하고, 제63조는 고속도로·자동차전용도로 통행·횡단을 금지한다. 따라서 **도로 등급만으로 보행 금지를 판단할 수 없다.**
- 현재 필터로는 큰 차도를 빼면 연결이 크게 무너진다. 큰 차도에 벌점을 주려면 크기의 근거가 필요한데 없다.
- 보도 유무 자료 후보: 국토지리정보원 수치지형도 등. **존재·제주 범위·이용조건 미확인.**

### 5.5 태그 채움률 (길이 기준, 차도+보행로)

보도 정보 1.3%(붙은 보도 0.3%), 조명 0.7%, 경사 0.5%, 제한속도 2.3%, 포장 14.9% → 보도·조명·경사·차량 소요시간은 OSM으로 채울 수 없다.

### 결론

예비 점검으로는 OSM이 섬 단위 연결 구조와 지방도 규모에서 큰 결함을 보이지 않았다. 경로 정확성(상용 길찾기 대비), 읍면별 골목 완전성, 보도 유무는 검증하지 않았다.

### 6.1 함께 쓸 때의 위험 (codex 검토 반영)

- **두 도로망 대응:** 교통 API는 표준노드링크 링크ID 기준이고 경로 그래프는 OSM이다. 구간 분할·방향·교차로 구조가 달라 다대다 대응이 생기면 통행시간이 중복되거나 잘못 배분된다. 매칭 방법과 검증(표본 구간 대조)이 필요하다. 대안은 차량 경로만 표준노드링크 그래프로 계산하는 것.
- **보도 공간 매칭:** 보도 면/선이 가까운 OSM 길에 속한다는 보장이 없다(좌표계, 위치 오차, 도로 양쪽, 입체교차). 매칭 규칙은 휴리스틱이 되므로 표본 검증 필수.
- **라이선스 결합:** OSM(ODbL)과 공공누리 제1유형·포털 자료를 합친 결과를 배포할 때 ODbL 공유 의무 범위를 원문으로 확인해야 한다. 미확인.
- **시점·버전:** 교통 API의 링크 버전과 내려받은 표준노드링크 버전이 같아야 한다. 실시간 값의 지연·만료 기준도 정해야 한다.

## 10. 행정동(읍면동) 경계 (2026-11-18 추가)

- 쓰임: 지역 공백 분석(REQUIREMENTS §2 E01)에서 사용자가 말한 읍면동의 범위. 사용자는 동네 이름이나 장소 이름만 입력한다.
- 원자료: 통계청 SGIS 행정동 경계(공공누리 제1유형). 가공본 vuski/admdongkor `ver20261001/HangJeongDong_ver20261001.geojson`(CC BY 4.0).
- 받는 법: `uv run python scripts/fetch_admdong.py` → `data/processed/jeju-admdong.geojson`(제주 43개 읍면동). 원본 SHA-256 `843ece3a…a605`(스크립트에 전체 값), 다르면 저장하지 않음.
