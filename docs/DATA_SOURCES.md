## 3. 수집 환경 제약 (2026-11-03)

이 개발 세션의 클라우드 환경은 네트워크 정책상 `www.jejudatahub.net`, `www.data.go.kr`,
`apis.data.go.kr`, `api.odcloud.kr`, `www.openstreetmap.org`, `overpass-api.de`,
`download.geofabrik.de` 접속이 거부되었다(HTTP CONNECT 403). 해결 방법: 환경 설정의 Network access에서
해당 도메인을 허용하거나, 로컬에서 원본 파일을 내려받아 `data/raw/`에 제공.
